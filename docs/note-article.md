# スマホの中に、本物のDebianデスクトップを。「LDFA」正式版(v1.0.0)を公開しました

スマートフォンの中に、**本物のLinuxデスクトップ環境**をまるごと一つ、アプリとして用意しました。

**LDFA（Linux Desktop for Android）** は、Android端末の中に **Debian 12（Bookworm）+ XFCEデスクトップ** を構築し、たった一つのアプリの中で操作できるようにするプロジェクトです。このたび、最初の正式版 **v1.0.0** を公開しました。

追加のアプリも、root化も要りません。1つのアプリを開くだけで、見慣れたLinuxのデスクトップが、あなたのスマホの画面に立ち上がります。

> 📦 GitHub（ダウンロード）: https://github.com/hatake716/LDFA/releases/tag/v1.0.0

## 「スマホのデスクトップモード」とは、まったくの別物です

最近のスマートフォンには、外部ディスプレイにつなぐと画面がPC風になる「デスクトップモード」があります。あれはとても便利ですが、中身はあくまで**Androidのアプリ**が並んでいるだけです。Androidアプリを、大きな画面で、ウィンドウっぽく並べているに過ぎません。

**LDFAが提供するのは、それとは根本的に違うもの**です。動いているのは、正真正銘の **Debian GNU/Linux** と、その上で動く **XFCEデスクトップ環境**です。

- ファイルマネージャ（Thunar）でファイルを操作し、
- 本物の **Google Chrome（Linux版）** でWebサイトやGoogleアカウントにログインし、
- ターミナルから `apt install` でパッケージを追加し、
- `npm install -g` でコマンドラインツールを導入する。

これらはすべて、Androidの機能を借りているのではなく、**Linuxそのものが動いているから**できることです。スマホの上に、小さなDebian PCが一台まるごと収まっている——それがLDFAです。

【スクショ挿入: desktop.png — Android上で動作するDebian XFCEデスクトップ。デスクトップアイコン、上部パネル、Thunarファイルマネージャ、そして画面下部の特殊キーバー（ESC / CTRL / ALT / 矢印 / HOME / END / PGUP / PGDN）まで揃っている】

しかも、これを実現するために、外部の **Termux**、**Termux:X11**、**VNCクライアント** といったアプリを別々に入れて連携させる必要はありません。ターミナル互換ランタイム、X11サーバー、X11ビューア、Debian PRoot、XFCE、日本語入力環境——**必要なものはすべて1つのアプリに内蔵**しています。「複数のアプリを入れて、設定して、つなぐ」という手間を、まるごと無くしました。

## 主な機能

### 1. 本物のXFCEデスクトップを、ネイティブ描画で

XFCEデスクトップを、内蔵のX11ビューア（Termux:X11ベース）へ**直接描画**します。タッチ・マウス・物理キーボード・ソフトウェアキーボードで操作でき、縦横の画面回転にも追従します。

【スクショ挿入: xfce.png — XFCEデスクトップの全景。上部パネル、デスクトップアイコン、下部の特殊キーバー】

【スクショ挿入: desktop-landscape.png — 横向きに回転しても、同じセッションのままデスクトップが画面の向きに追従する】

### 2. Google Chrome 公式版を自動導入

環境の作成時に、Googleの公式Linuxパッケージから **Google Chrome stable** を自動でインストールします（64bit環境）。Webサイトの閲覧はもちろん、Googleアカウントへのログインもできます。ソフトウェアキーボードでのパスワード入力にも対応しています。

【スクショ挿入: chrome.png — Debian上で起動したGoogle Chrome（公式版）。初回起動時の利用規約が表示されている】

### 3. Node.js とコマンドラインツール

Node.js 22 LTS（公式静的ビルド）を自動導入し、`node` / `npm` / `npx` をすぐに使えるようにします。`npm install -g` で入れたCLIは、ターミナルからそのまま実行できます（PRoot環境なので `sudo` も不要）。開発ツールを持ち歩きたい方にも。

### 4. 音まで、ちゃんと鳴る

Debian・XFCE・Chromeの音声を、アプリ内蔵のPulseAudioブリッジ経由でAndroidのスピーカーへ出力します。動画の音声が、実際にスマホから鳴ります。技術的には、PRoot環境特有の制約（共有メモリが渡せない）を回避するため、共有メモリを無効化し、専用のUnixソケットを隔離して配置しています。**実機で可聴出力を確認済み**です。

### 5. 日本語入力と、日本語環境

日本語ロケール、Noto CJKフォント、日本語キーボード、Fcitx5 + Mozc をあらかじめ構築済み。インストール直後から日本語入力ができます。

### 6. 内蔵ツールと、透明な状態表示

内蔵ターミナルからDebianを保守でき、システムの状態（実行環境・ファイル共有・Linux実行基盤）は常に可視化されます。うまく動かないときの「自動修復」も用意しています。Android共有ストレージは、Debian側の `/mnt/android` から読み書きできます。

【スクショ挿入: tools.png — ツール画面。実行中のXFCEを表示する導線、内蔵ターミナル、そしてシステムの状態がすべて緑のチェックで表示されている】

### 7. Electron製アプリにも対応

Claude Desktop、VS Code、SlackなどのElectron/Chromium製アプリは、PRoot環境ではそのままだと起動しません（サンドボックスの初期化に失敗するため）。LDFAは、デスクトップ起動のたびにインストール済みのElectronアプリを自動検出し、起動に必要な設定を自動で補います。手動で後から入れたアプリも、次回の起動で自動的に立ち上がるようになります。

## 前回（v0.9.0）からの改善点

v0.9.0のプレリリースから、正式版v1.0.0までに、以下を改善しました。

### ✅ 表示倍率を 100〜250% に拡張（25%刻み）

高DPIの端末ではデスクトップが小さく表示されがちです。**設定 → 表示 → 表示倍率** から、デスクトップ全体（文字・アイコン・パネル・ウィンドウ・Chromeまで）の大きさを **100%〜250%（25%刻み）** で選べるようにしました。内蔵X11サーバー自身の表示スケール機能を使うため、すべてが一律にきれいに拡大されます。起動中でも即座に反映されます。

【スクショ挿入: settings-display.png — 設定 → 表示。表示倍率のプリセット（100〜250%）と、特殊キーバーのON/OFFスイッチ】

### ✅ 特殊キーバーのON/OFFを追加

タッチ操作でも `Ctrl+C` や矢印キー、`ESC`、`HOME`／`END` を送れるよう、画面下部に特殊キーの行を表示できます。物理キーボードを使うときや画面を広く使いたいときは、**設定 → 表示** のスイッチでOFFにして非表示にできます。切り替えは起動中でも即時反映されます。

### ✅ 起動を高速化

デスクトップ起動時の処理を見直し、成功時に無駄になっていた重い処理（Linuxへのログイン処理）を1回分削減し、固定の待ち時間もいくつか短縮しました。安全性（最悪ケースの保証）は保ったまま、2回目以降の起動が速くなっています。

### ✅ 上書き更新の安定化

以前は、新しいバージョンをインストールしようとすると「アプリはインストールされていません」と出て失敗することがありました。これは署名鍵のずれが原因でした。署名鍵をリポジトリに固定したことで、**どの環境でビルドしても同じ鍵で署名され、旧バージョンへの上書き更新が確実にできる**ようになりました。

## 使う前に知っておいてほしいこと

正直にお伝えしておきます。

- **PRootは完全なLinux仮想マシンではありません。** DebianはAndroidカーネル上のPRootとして動作します。systemdや一部のカーネル機能、低レベルな操作は、通常のPCのDebianとは挙動が異なります。
- **Chromeは `--no-sandbox` で動作します。** Android PRoot環境ではChrome本来のサンドボックスを確立できないため、互換オプションで起動しています。通常のLinux版Chromeよりコンテンツの隔離が弱くなるので、信頼できないサイトやファイルの扱いには注意してください。
- **公式Termuxとは同時インストールできません。** 内蔵ランタイムは互換性のため `com.termux` のIDを使用します。既存のTermuxに大事なデータがある場合は、必ずバックアップしてください。
- **一部の端末は継続検証中です。** ARM64の16KBページサイズ端末での長時間動作は、引き続き検証中です。日常データを置く唯一の環境としてではなく、バックアップを取ったテスト環境としてお使いください。
