LDFAの特徴

Linuxの導入から表示まで、1つのアプリで。

Linuxの実行環境、画面表示、日本語入力をまとめて準備します。導入状況とログを確認でき、中断した場合は保存済みの環境から再開できます。

SELF-CONTAINED
📦

すべてアプリ内蔵

Termux 互換ランタイムと X11 表示サーバーをアプリに同梱。別アプリのインストールも、アプリ間の権限連携も不要です。Android が表示・入力・ライフサイクルを直接所有します。

DIRECT-BINDER X11
🖥️

ネイティブ描画

Xorg をアプリ内の専用プロセスで動かし、Binder 経由で直接 Android の Surface / EGL へ描画。TCP 越しの VNC に頼らず、低遅延でデスクトップを表示します。通常描画と互換描画を検査し、表示できない場合は診断を表示します。

AUDIO BRIDGE
🔊

音声出力の仕組みを内蔵

Linuxの音声をAndroidへ渡すPulseAudioを同梱しています。出力先はAndroidの設定を使用します。v1.2.2では実機での音声試聴は未確認です。

できること

本物の Linux デスクトップが、手のひらに。

1 タップ管理

環境を作って、開くだけ

ホーム画面で環境を追加し、「Debian XFCE を開く」を押すだけ。作成・起動・停止・削除がカード 1 枚で完結します。状態は常に色と文言で一目でわかります。

  • ✓複数の Debian 環境を保存して切り替え
  • ✓起動・停止はワンタップ、進捗もその場で表示
  • ✓2 回目以降の起動を高速化する起動キャッシュ内蔵
準備状況を確認

内蔵ツールと、透明な状態表示

ツール画面から Linux 画面と内蔵ターミナルを直接開けます。「システムの状態」は、内蔵実行環境とLinux実行基盤の準備状況を確認できます。中断した導入の再開と詳細ログへの入口も用意しています。

  • ✓内蔵ターミナルで Debian を直接操作
  • ✓内蔵実行環境・Linux実行基盤の状態を表示
  • ✓保存済みの環境を使って、中断した導入を再開
Chrome も、ファイルも

使い慣れたアプリが、そのまま動く

Google Chrome 公式版を自動導入。Thunar ファイルマネージャ、端末、テキストエディタといった XFCE のアプリがそのまま使えます。作成したファイルはアプリ内のLinux環境に保存されます。環境全体をバックアップして持ち出せます。

  • ✓Google Chrome 公式版を作成時に自動インストール
  • ✓XFCE 標準アプリ（端末・ファイル・エディタ）
  • ✓Linux環境の保存とバックアップ
日本語も、回転も

日本語入力と、画面の向きに対応

日本語ロケール・Noto CJK フォント・Fcitx5 + Mozc をあらかじめ構築済み。縦横の回転にもデスクトップが追従し、同じセッションのまま表示を作り直します。

  • ✓Fcitx5 + Mozc による日本語入力
  • ✓縦・横の回転に追従する Surface 再生成
  • ✓ソフトキーボード表示中も画面を可視領域へ調整

横向き表示 — 同じセッションのまま Surface を再生成

見やすさは、自分で決める

表示倍率と、特殊キー

高 DPI の画面でも、デスクトップ全体を 100〜250%（25%刻み）で拡大できます。文字・アイコン・パネル・Chrome までまとめて大きくなります。画面下部の特殊キーバー（ESC / CTRL / ALT / 矢印など）は、ワンタップで表示・非表示を切り替えられます。

  • ✓デスクトップ全体の表示倍率 100〜250%（25%刻み）
  • ✓起動中でも即時に反映（パネルは自動再読み込み）
  • ✓特殊キーバー（ESC / CTRL / ALT / 矢印）の ON / OFF
保存と復元

環境まるごと、バックアップと移行

作り込んだ Debian 環境を、1 つの .ldfa ファイルに丸ごと保存。同じCPUアーキテクチャのAndroid端末へ、新しい環境として復元できます。機種変更や環境の複製にそのまま使えます。

  • ✓停止中の環境をバックアップ。Android 10以降ではダウンロード/LinuxDesktopに保存
  • ✓復元は常に新しい環境として追加。既存の環境は上書きしません
  • ✓SHA-256で破損を検知。Android 8〜9では表示される保存先から端末外へコピー

3 ステップで、デスクトップが立ち上がる。

初回にLinuxをダウンロードして構築します。以降は環境を選んで開けます。

STEP 01

アプリを開く

APKをインストールして開き、必要な空き容量と通信を確認します。root化や別の表示アプリは不要です。

STEP 02

Linuxを導入

名前を入力し「Linuxをインストール」を押します。Debian 12・XFCE・日本語入力・Chrome・音声クライアントを自動で構築します。

STEP 03

デスクトップを開く

「デスクトップを開く」をタップ。ネイティブ X11 でデスクトップが表示され、そのまま操作を始められます。

インストール

入手して、始める。

v1.2.2の署名済みAPKをGitHubのプレリリースページから入手できます。Pixel 10aでは上書き更新とアプリ起動、端末内APKの照合を確認済みです。ARM64実機でのLinuxの導入・実行は未確認です。旧アプリIDや別の署名から移行する場合は、バックアップと復元を使います。

  1. APK をダウンロード

    Releases v1.2.2 から LDFA-v1.2.2-release.apk を取得します。

  2. 提供元不明のアプリを許可

    Play ストア外の APK のため、端末の設定でインストール元の許可が必要な場合があります。

  3. アプリを開いて初回セットアップ

    空き容量5GB以上と通信を確認し、名前を入力して「Linuxをインストール」を押します。初回の所要時間は端末と回線により変わります。

  4. 環境を追加して起動

    導入が完了したら「デスクトップを開く」で起動します。バックアップからの復元にも対応しています。

ご注意 — PRoot 内では Chrome の通常サンドボックスを確立できないため --no-sandbox で動作します。通常の Chrome と同等の隔離は保証しません（詳細は SECURITY.md）。マイク入力は対象外（再生専用）です。
