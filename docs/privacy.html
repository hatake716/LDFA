LDFA プライバシーポリシー

最終更新日: 2026年8月28日

LDFA（Linux Desktop for Android、アプリID: com.hatake716.linuxdesktop、以下「本アプリ」）は、hatake716（以下「開発者」)が提供する、Android 端末上で Linux デスクトップ環境を実行するアプリです。

1. 収集する情報

本アプリは、個人情報を収集・送信しません。

  • アカウント登録はありません。
  • 解析（アナリティクス）SDK・広告 SDK を含みません。
  • 端末識別子、位置情報、連絡先などにアクセスしません。
  • クラッシュレポート等を開発者のサーバーへ自動送信することはありません（開発者はサーバーを運用していません）。

2. ネットワーク通信について

本アプリは、次の目的でのみインターネットへ接続します。いずれも「ダウンロード」であり、ユーザーのデータを外部へ送信するものではありません。

  • Debian 公式リポジトリ等からの Linux 環境（OSイメージ・ソフトウェアパッケージ）の取得
  • ユーザーの選択による Google Chrome、Node.js など追加ソフトウェアの取得

Linux 環境内でユーザーが自ら行う通信（ブラウザの閲覧、各種 CLI ツールへのログイン等）は、それぞれのソフトウェア・サービス提供者のプライバシーポリシーに従います。

3. 端末内に保存されるデータ

Linux 環境（Debian のファイル・設定・ユーザーが作成したデータ）は、すべて端末内のアプリ専用領域にのみ保存されます。バックアップ機能を使用した場合、バックアップファイル（.ldfa）は端末の「ダウンロード」フォルダに保存されます。これらが開発者や第三者へ送信されることはありません。アプリをアンインストールすると、アプリ専用領域のデータは削除されます。

4. 権限について

  • インターネット / ネットワーク状態: 上記2.のダウンロードに使用します。
  • 通知: インストールやデスクトップ実行中の状態表示に使用します。
  • フォアグラウンドサービス: Linux デスクトップと表示サーバーを画面消灯後も維持するために使用します。
  • ストレージ権限（外部ストレージへのアクセス権限）は使用しません。

5. 子どもの利用について

本アプリは 18 歳以上のユーザーを対象としており、子どもを対象としたサービスではありません。

6. ポリシーの変更

本ポリシーを変更する場合は、本ページで告知します。

7. お問い合わせ

本ポリシーに関するお問い合わせ: acesmash@gmail.com

LDFA Privacy Policy

Last updated: August 28, 2026

LDFA (Linux Desktop for Android, application ID com.hatake716.linuxdesktop, the “App”) is provided by hatake716 (the “Developer”) and runs a Linux desktop environment on Android devices.

1. Information We Collect

The App does not collect or transmit any personal information.

  • No account registration exists.
  • No analytics or advertising SDKs are included.
  • The App does not access device identifiers, location, or contacts.
  • No crash reports or telemetry are sent to the Developer (the Developer operates no servers).

2. Network Access

The App connects to the Internet only to download software: the Debian operating system and packages from official repositories, and — at the user’s choice — additional software such as Google Chrome and Node.js. No user data is uploaded. Any network activity the user performs inside the Linux environment (web browsing, logging into CLI tools, etc.) is governed by the privacy policies of those respective services.

3. Data Stored on the Device

Linux environments (Debian files, settings, and user-created data) are stored only in the App’s private storage on the device. Backup files (.ldfa) created by the backup feature are saved to the device’s Download folder. Nothing is transmitted to the Developer or third parties. Uninstalling the App deletes its private data.

4. Permissions

  • Internet / network state: used for the downloads described above.
  • Notifications: show installation and desktop status.
  • Foreground services: keep the Linux desktop and its display server running while the screen is off.
  • No external-storage permissions are used.

5. Children

The App is intended for users aged 18 and over and is not directed at children.

6. Changes

Changes to this policy will be announced on this page.
